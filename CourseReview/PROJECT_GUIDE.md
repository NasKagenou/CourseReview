# คู่มืออ่านระบบ CourseReview แบบเข้าใจง่าย

เอกสารนี้อธิบายว่าแต่ละส่วนของเว็บทำหน้าที่อะไร และข้อมูลเดินทางจากหน้าจอไปถึงฐานข้อมูลอย่างไร เหมาะสำหรับผู้อ่านที่ยังไม่คุ้นกับการเขียนโปรแกรม

## ภาพรวมการทำงาน

เว็บทำงานเป็นลำดับคล้ายการส่งแบบฟอร์ม:

1. ผู้ใช้เปิดหน้าเว็บ เช่น `index.php`
2. ไฟล์หน้านั้นตรวจว่าผู้ใช้เข้าสู่ระบบหรือยัง และอ่านข้อมูลจาก URL หรือแบบฟอร์ม
3. หน้าเว็บเรียกคลาสใน `classes/` ให้ค้นหา เพิ่ม แก้ไข หรือลบข้อมูล
4. คลาสใช้การเชื่อมต่อจาก `config/Database.php` เพื่อคุยกับ MySQL
5. ผลที่ได้ถูกนำมาแสดงเป็น HTML โดยแปลงข้อความด้วย `htmlspecialchars()` ก่อนแสดง

`$_GET` คือข้อมูลที่ติดมากับ URL เช่น `?id=DBM-201` ส่วน `$_POST` คือข้อมูลที่ส่งจากแบบฟอร์มโดยไม่แสดงไว้ใน URL ส่วน `$_SESSION` ใช้จำว่าผู้ใช้คนใดเข้าสู่ระบบและมีบทบาทอะไร

## วิธีอ่านคอมเมนต์และตามการทำงาน

คอมเมนต์ที่เพิ่มไว้ในไฟล์โค้ดใช้ภาษาง่าย ๆ เพื่อบอกว่าโค้ดส่วนนั้นทำหน้าที่อะไร รับข้อมูลจากไหน และส่งงานต่อให้คลาสหรือเมธอดใด คอมเมนต์เป็นข้อความอธิบายสำหรับคนอ่าน ไม่ได้สั่งให้เว็บทำงาน และลบหรือแก้ข้อความคอมเมนต์แล้วพฤติกรรมของหน้าเว็บจะเหมือนเดิม

- `// ...` คือคำอธิบายในไฟล์ PHP หรือ JavaScript
- `<!-- ... -->` คือคำอธิบายในส่วน HTML
- `/* ... */` คือคำอธิบายในไฟล์ CSS ซึ่งบอกหน้าที่การตกแต่ง ไม่ได้เปลี่ยนข้อมูลหรือคะแนน

ถ้าต้องการตามการทำงาน ให้เริ่มจากไฟล์หน้าจอที่ผู้ใช้เปิด แล้วดูว่าไฟล์นั้นสร้างคลาสอะไรและเรียกเมธอดไหน ตัวอย่างการส่งข้อเสนอวิชา:

1. ผู้ใช้กรอกแบบฟอร์มใน [suggest_course.php](./student/suggest_course.php) แล้วส่งด้วย `POST`
2. หน้านี้เรียก `Suggestion::create()` เพื่อบันทึกรายการลงฐานข้อมูล
3. ถ้าบันทึกสำเร็จ จึงเรียก `Log::addLog()` เพื่อเก็บประวัติ
4. ผู้ดูแลเปิด `admin/courses/manage_suggestions.php` ซึ่งเรียก `Suggestion::readAll()` มาแสดง
5. เมื่ออนุมัติ ระบบเรียก `Course::create()` เพื่อสร้างวิชาจริง และ `Suggestion::updateStatus()` เพื่อเปลี่ยนสถานะข้อเสนอ

ชื่อนี้อ่านได้ว่า `Suggestion` คือคลาส และ `create()` คือเมธอดของคลาสนั้น เครื่องหมาย `->` เช่น `$suggestionObj->create(...)` หมายถึงเรียกเมธอดผ่านออบเจกต์ที่สร้างไว้ ส่วน `::` เช่น `Suggestion::create()` เป็นการเขียนชื่อคลาสกับเมธอดให้อ่านสั้น ๆ ในคู่มือนี้

## ตัวอย่างสำคัญ: คะแนนดาวและ Top 5 วิชา

### ตอนให้คะแนน

1. ผู้ใช้เปิด [course_detail.php](./course_detail.php) โดยส่งรหัสวิชาใน URL เช่น `course_detail.php?id=DBM-201`
2. แบบฟอร์มรีวิวในหน้านี้มีช่อง `rating` ให้เลือก 1–5 ดาว และช่อง `comment` สำหรับเขียนประสบการณ์
3. เมื่อกดส่ง แบบฟอร์มส่งข้อมูลด้วย `POST` กลับมาที่หน้าเดิม โดยปุ่มจะส่งชื่อ `submit_review` มาด้วย
4. ส่วนประมวลผลด้านบนของ `course_detail.php` ตรวจพบ `submit_review` แล้วเรียก `Review::create()`
5. [Review.php](./classes/Review.php) บันทึกรหัสผู้ใช้ รหัสวิชา คะแนน และข้อความลงตาราง `reviews`
6. เมื่อโหลดหน้าใหม่ ส่วนแสดงรีวิวอ่านข้อมูลผ่าน `Review::readByCourse()` แล้วแสดงดาวจากคะแนนที่บันทึกไว้

### ตอนจัดอันดับ Top 5

1. หน้า [index.php](./index.php) เรียก `Course::getTopRated()` ก่อนสร้างรายการหน้าแรก
2. [Course.php](./classes/Course.php) ใช้คำสั่ง SQL รวมรีวิวทั้งหมดแยกตามวิชา เพื่อหาคะแนนเฉลี่ย (`AVG`) และจำนวนรีวิว (`COUNT`)
3. คะแนนที่ใช้จัดอันดับเป็นคะแนนถ่วงน้ำหนัก: `(คะแนนเฉลี่ย × จำนวนรีวิว + 3.5 × 3) ÷ (จำนวนรีวิว + 3)` ค่าเฉลี่ยตั้งต้น 3.5 และน้ำหนัก 3 รีวิวช่วยไม่ให้วิชาที่มีรีวิวน้อยมากขึ้นอันดับสูงเพราะคะแนนเพียงรายการเดียว
4. SQL เรียงตามคะแนนถ่วงน้ำหนักจากมากไปน้อย และ `LIMIT 5` จำกัดผลให้เหลือ 5 วิชา
5. `index.php` วนอ่านผลทีละวิชา แสดงลำดับ รหัส ชื่อ คะแนนเฉลี่ยจริงที่ปัดเป็นทศนิยม 1 ตำแหน่ง และจำนวนรีวิว
6. รูปดาวสีส้มที่เห็นมาจาก `<span class="stars">★</span>` และ CSS `.stars` ใน [style.css](./assets/css/style.css) มีหน้าที่ตกแต่งสี/ขนาดเท่านั้น ไม่ได้คำนวณอันดับ

ดังนั้น **ลำดับ Top 5 ใช้คะแนนถ่วงน้ำหนัก** แต่ **ตัวเลขที่แสดงข้างดาวเป็นคะแนนเฉลี่ยจริง** ทั้งสองค่าอาจต่างกันได้โดยตั้งใจ

## แผนที่ไฟล์และหน้าที่

### การเชื่อมต่อและส่วนที่ใช้ร่วมกัน

- [Database.php](./config/Database.php): ตั้งค่า URL หลัก เขตเวลา และสร้างการเชื่อมต่อ PDO ไปยังฐานข้อมูล `course_review_db`
- [header.php](./includes/header.php): เริ่ม HTML ของทุกหน้า ตั้งชื่อหน้า และโหลด CSS กลาง
- [navbar.php](./includes/navbar.php): เลือกแถบนำทางตามบทบาทผู้ใช้
- [navbar_user.php](./includes/navbar_user.php): เมนูผู้ใช้ทั่วไป เช่น หน้าแรก ตารางเรียน และออกจากระบบ
- [navbar_admin.php](./includes/navbar_admin.php): เมนูผู้ดูแลระบบและทางกลับหน้าเว็บนักศึกษา
- [footer.php](./includes/footer.php): ปิดหน้าเว็บ แสดงลิขสิทธิ์ และสร้างวงแสงตกแต่งที่ลอยขึ้น
- [style.css](./assets/css/style.css): สี ฟอนต์ ปุ่ม การ์ด ตาราง และการจัดหน้าให้เหมาะกับจอเล็ก

### บัญชีผู้ใช้

- [login.php](./auth/login.php): รับชื่อผู้ใช้/รหัสผ่าน เรียก `User::login()` แล้วเก็บรหัสผู้ใช้กับบทบาทไว้ใน session ก่อนพาไปหน้าที่เหมาะสม
- [register.php](./auth/register.php): ตรวจข้อมูลและการยืนยันรหัสผ่าน แล้วเรียก `User::register()` เพื่อสร้างบัญชีนักศึกษา
- [change_password.php](./auth/change_password.php): ตรวจรหัสผ่านเดิมและรหัสใหม่ แล้วเรียก `User::changePassword()`
- [logout.php](./auth/logout.php): ล้าง session และพากลับหน้าเข้าสู่ระบบ
- [User.php](./classes/User.php): รวมการตรวจบัญชี สมัครสมาชิก เปลี่ยนรหัสผ่าน และนับผู้ใช้ รหัสผ่านใหม่ถูกแฮชก่อนเก็บ

### หน้ารายวิชาและรีวิว

- [index.php](./index.php): ตรวจการเข้าสู่ระบบ แสดง Top 5 ค้นหา/กรองรายวิชา เรียงผล และแบ่งหน้า
- [course_detail.php](./course_detail.php): แสดงข้อมูลรายวิชา ให้นักศึกษาและแอดมินเขียนรีวิว/ตอบกลับ/กดโหวตได้; เฉพาะนักศึกษาบันทึกวิชาเข้าตารางเรียน และแอดมินลบรีวิวได้
- [Course.php](./classes/Course.php): อ่าน เพิ่ม แก้ไข ลบ ค้นหา และจัดอันดับรายวิชา
- [Review.php](./classes/Review.php): บันทึกและอ่านรีวิว คำตอบ และโหวตที่เป็นประโยชน์
- [Log.php](./classes/Log.php): บันทึกกิจกรรมสำคัญ เช่น เพิ่มรีวิวหรือลบรีวิว เพื่อให้ผู้ดูแลตรวจย้อนหลัง

### ตารางเรียนและโปรไฟล์

- [schedule.php](./student/schedule.php): อ่านตารางของผู้ใช้ รวมหน่วยกิต และวางบล็อกวิชาตามวันเวลา
- [edit_schedule.php](./student/edit_schedule.php): ตรวจว่ารายวิชาเป็นของผู้ใช้ แล้วบันทึกวันและเวลาเรียน
- [Schedule.php](./classes/Schedule.php): เพิ่ม/ลบวิชาในรายการส่วนตัว อ่านตาราง และปรับเวลาเรียน
- [profile.php](./student/profile.php): แสดงชื่อ บทบาท และแท็บประวัติรีวิว วิชาที่บันทึก คอร์สฟรีที่บันทึก และข้อมูลบัญชี
- [Bookmark.php](./classes/Bookmark.php): เพิ่ม/นำคอร์สฟรีออกจากรายการบันทึก และอ่านคอร์สที่ผู้ใช้เก็บไว้

### คอร์สเรียนฟรี

- [course_free.php](./course_free.php): แสดงคลังคอร์ส กรองตามคำค้น หมวดหมู่ ภาษา และใบประกาศ พร้อมปุ่มบันทึกคอร์ส
- [FreeCourse.php](./classes/FreeCourse.php): อ่าน เพิ่ม แก้ไข ลบคอร์สฟรี จัดการรูปปก และนับจำนวนคอร์ส
- `admin/free_courses/manage_free_courses.php`: แสดงคอร์สทั้งหมดให้ผู้ดูแลจัดการ
- `admin/free_courses/add_free_course.php`: รับข้อมูลคอร์สใหม่และรูปปก
- `admin/free_courses/edit_free_course.php`: โหลดข้อมูลเดิมให้แก้ไข และเปลี่ยนรูปปกเมื่อมีไฟล์ใหม่

### ข้อเสนอแนะและงานของผู้ดูแล

- [suggest_course.php](./student/suggest_course.php): นักศึกษาส่งข้อมูลวิชาใหม่เพื่อรอการตรวจสอบ
- [Suggestion.php](./classes/Suggestion.php): บันทึกข้อเสนอ อ่านรายการ และเปลี่ยนสถานะ
- `admin/courses/manage_suggestions.php`: ผู้ดูแลอนุมัติข้อเสนอโดยสร้างวิชาจริงใน `courses` หรือปฏิเสธข้อเสนอ
- [feedback.php](./student/feedback.php): นักศึกษาส่งปัญหาหรือข้อเสนอแนะ
- [Feedback.php](./classes/Feedback.php): บันทึกข้อความและเปลี่ยนสถานะการดำเนินการ
- `admin/system/manage_feedbacks.php`: ผู้ดูแลอ่านข้อความและทำเครื่องหมายว่าแก้ไขแล้ว
- `admin/system/activity_logs.php`: แสดงประวัติกิจกรรมที่ `Log.php` บันทึกไว้
- [admin/index.php](./admin/index.php): สรุปจำนวนผู้ใช้ วิชา รีวิว คอร์สฟรี และแสดงกราฟภาพรวม
- `admin/courses/manage_courses.php`, `add_course.php`, `edit_course.php`: หน้ารายการ เพิ่ม และแก้ไขรายวิชาหลัก

### ฐานข้อมูลและข้อมูลตัวอย่าง

[setup.php](./setup.php) สร้างฐานข้อมูล ตาราง และข้อมูลจำลองเพื่อทดลองใช้ **ข้อควรระวัง: สคริปต์นี้มีคำสั่ง `DROP DATABASE` จึงลบฐานข้อมูล `course_review_db` เดิมทั้งหมดก่อนสร้างใหม่ ห้ามเรียกใช้กับฐานข้อมูลที่มีข้อมูลจริงซึ่งต้องการเก็บ**

ก่อนนำไปลอง ให้ตรวจค่าเชื่อมต่อใน [Database.php](./config/Database.php) ให้ตรงกับ MySQL ในเครื่อง แล้วเปิด `setup.php` เฉพาะเมื่อต้องการเริ่มฐานข้อมูลทดลองใหม่เท่านั้น

ตารางหลักเชื่อมกันดังนี้:

- `users`: บัญชีและบทบาทผู้ใช้
- `categories` → `courses`: หมวดหมู่ที่รายวิชาสังกัด
- `courses` → `reviews`: รีวิวและคะแนนของแต่ละวิชา
- `reviews` → `review_votes` / `review_replies`: คะแนนโหวตและคำตอบของรีวิว
- `users` → `my_schedule`: รายวิชาที่ผู้ใช้เก็บและเวลาเรียนส่วนตัว
- `free_courses` → `free_course_bookmarks`: คอร์สฟรีและรายการที่ผู้ใช้บันทึก
- `course_suggestions`, `feedbacks`, `activity_logs`: ข้อเสนอวิชา ข้อความแจ้งปัญหา และประวัติกิจกรรม

## คำศัพท์ที่เจอบ่อย

- **คลาส**: กลุ่มคำสั่งที่รวมงานประเภทเดียวกัน เช่น `Review` รวมคำสั่งเกี่ยวกับรีวิว
- **เมธอด**: คำสั่งย่อยในคลาส เช่น `getTopRated()` คือคำสั่งดึงวิชาคะแนนสูง
- **SQL**: ภาษาที่ใช้สั่งฐานข้อมูล เช่น อ่าน (`SELECT`) หรือบันทึก (`INSERT`)
- **PDO**: เครื่องมือที่ PHP ใช้เชื่อมฐานข้อมูลและส่งคำสั่ง SQL
- **prepared statement**: วิธีเตรียมคำสั่ง SQL แล้วส่งค่าจริงแยกกัน ช่วยไม่ให้ค่าจากช่องกรอกกลายเป็นส่วนหนึ่งของคำสั่ง SQL
- **session**: พื้นที่จำสถานะผู้ใช้ระหว่างเปิดหน้าเว็บหลายหน้า
- **redirect**: การพาเบราว์เซอร์ไปหน้าอื่นหลังทำรายการ เช่น หลังบันทึกรีวิว
